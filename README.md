# บันทึกแปลงเนเปียร์ ห้วยแร่

เว็บแอปบันทึกการปลูก การตัด กิจกรรมรายวัน (ไถพรวน ให้ปุ๋ย รดน้ำ ฯลฯ) ชนิดปุ๋ย และค่าใช้จ่าย ของแปลงหญ้าเนเปียร์ห้วยแร่
ใช้บนมือถือได้ มีผู้ใช้ 3 ระดับ: **Admin**, **ผู้บันทึก (Staff)**, **ผู้ดู (Viewer)**

เทคโนโลยี: React + Vite (หน้าเว็บ) · Supabase (ฐานข้อมูล + ล็อกอิน + เก็บรูป) · Vercel (โฮสต์เว็บ) ทั้งหมดใช้แพ็กเกจฟรีได้

## ติดตั้งและเผยแพร่ (ประมาณ 30–60 นาที)

### 1. สร้างฐานข้อมูลบน Supabase
1. สมัครที่ https://supabase.com แล้วกด **New project** ตั้งชื่อ เช่น `napier-huairae` เลือก Region **Southeast Asia (Singapore)** ตั้งรหัสผ่านฐานข้อมูลแล้วจดเก็บไว้
2. เมนูซ้าย **SQL Editor** > **New query** คัดลอกทั้งไฟล์ [`supabase/schema.sql`](supabase/schema.sql) มาวาง กด **Run** (ต้องขึ้น Success)
3. (ไม่บังคับ) รัน [`supabase/sample-plots.sql`](supabase/sample-plots.sql) เพื่อใส่แปลงตัวอย่าง 3 แปลง แก้หรือลบได้ภายหลังในหน้า ตั้งค่า
4. เมนู **Authentication** > **Sign In / Providers** > **Email**: เปิดไว้ (ค่าเริ่มต้น) ถ้าไม่อยากให้ต้องยืนยันอีเมล ปิด **Confirm email** ได้
5. เมนู **Project Settings** > **API** คัดลอก 2 ค่า: **Project URL** และ **anon public key**

### 2. นำเว็บขึ้น Vercel
1. สมัครที่ https://vercel.com ด้วยบัญชี GitHub
2. กด **Add New… > Project** เลือก repository นี้ > **Import**
3. ในหัวข้อ **Environment Variables** ใส่
   - `VITE_SUPABASE_URL` = Project URL จากข้อ 1.5
   - `VITE_SUPABASE_ANON_KEY` = anon public key จากข้อ 1.5
4. กด **Deploy** รอ 1–2 นาที จะได้ลิงก์ เช่น `https://napier-huairae.vercel.app`
5. กลับไป Supabase > **Authentication** > **URL Configuration** ใส่ลิงก์นี้ใน **Site URL** (เพื่อให้ลิงก์ยืนยันอีเมลกลับมาที่เว็บ)

### 3. เริ่มใช้งาน
1. เปิดลิงก์เว็บ กด **สมัครใช้งาน** ด้วยอีเมลของคุณ — **คนแรกที่สมัครจะเป็น Admin อัตโนมัติ**
2. หน้า **ตั้งค่า**: เพิ่ม/แก้แปลง ชนิดปุ๋ย (ใส่ราคาต่อหน่วยเพื่อให้คำนวณค่าปุ๋ยอัตโนมัติ) ชนิดกิจกรรม หมวดค่าใช้จ่าย
3. หน้า **ตั้งค่า > ผู้ใช้**: พิมพ์อีเมลคนที่จะให้ใช้ เลือกบทบาท กด **เชิญ** แล้วส่งลิงก์เว็บให้เขาไปกด “สมัครใช้งาน” ด้วยอีเมลนั้น
   - คนที่สมัครโดยไม่ได้รับเชิญ จะอยู่สถานะ “รออนุมัติ” และไม่เห็นข้อมูลใดๆ จนกว่า Admin จะเปลี่ยนบทบาทให้
4. บนมือถือ เปิดลิงก์แล้วกด **เพิ่มไปที่หน้าจอหลัก (Add to Home Screen)** จะใช้งานเหมือนแอป

## สิทธิ์การใช้งาน

| | Admin | ผู้บันทึก | ผู้ดู |
|---|---|---|---|
| จัดการผู้ใช้ แปลง ชนิดปุ๋ย/กิจกรรม | ✓ | | |
| บันทึกปลูก ตัด กิจกรรม ค่าใช้จ่าย | ✓ | ✓ | |
| ลบ/แก้บันทึก | ทุกรายการ | ของตัวเอง ภายใน 7 วัน | |
| ดูข้อมูล รายงาน ส่งออก CSV | ✓ | ✓ | ✓ |

สิทธิ์ทั้งหมดบังคับที่ฐานข้อมูล (Row Level Security) ไม่ใช่แค่ซ่อนปุ่ม

## โครงสร้างข้อมูล
`sites` พื้นที่ · `plots` แปลง · `plantings` รอบปลูก · `harvests` การตัด (ครั้งที่ คำนวณอัตโนมัติ) · `activities` กิจกรรม ·
`fertilizers` ชนิดปุ๋ย · `activity_types` ชนิดกิจกรรม · `costs` ค่าใช้จ่าย · `cost_categories` หมวด · `profiles` ผู้ใช้ · `invitations` คำเชิญ ·
`plot_summary` (view) สรุปผลผลิต/ต้นทุนต่อแปลง

## สำรองข้อมูล
แพ็กเกจฟรีของ Supabase ไม่มีการสำรองที่กู้คืนเองได้ แนะนำกด **รายงาน > ส่งออก CSV** และ **ประวัติ > ส่งออก** เดือนละครั้ง
และโปรเจกต์ฟรีจะถูกพักถ้าไม่มีการใช้งาน 7 วัน (กด Restore ในหน้า Supabase ได้ ข้อมูลไม่หาย)
